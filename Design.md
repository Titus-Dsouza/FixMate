# FixMate — Design

## 1. Design Style

A clean, modern civic-tech interface that is simple, trustworthy, and easy to use.

## 2. Colour Themes

FixMate supports light and dark modes with a toggle that remembers the user's preference.

### Light Mode
- Background: #F8F8F3
- Cards: #FFFFFF
- Primary: #174D38
- Text: #252A27

### Dark Mode
- Background: #10251C
- Cards: #19352A
- Primary: #8BD5AD
- Text: #F1F5F2

### Complaint Status Colours
- Green: Completed and citizen-confirmed
- Yellow: AI verified or awaiting confirmation
- Orange: AI rejected
- Red: Unresolved

## 3. Citizen Interface

- File a Complaint
- My Complaints
- Politician & Area Report

## 4. Government Interface

- View assigned and overdue complaints
- Submit repair evidence
- Track monthly rankings

Only the reporting citizen can confirm that a complaint is resolved.

## 5. Layout

- Public homepage with top navigation
- Desktop dashboards with a sidebar
- Mobile-friendly forms and cards
- Simple Pune ward map with typed locality entry

## 6. UI Principles

- Clear buttons, readable text, and simple forms
- Consistent design across both themes
- Minimal animations and visual clutter
- Responsive layouts for mobile and desktop
- AI suggestions must be editable and clearly labelled
