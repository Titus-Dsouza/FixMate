 FixMate 🛠️
Spot it. Report it. Fix it.

FixMate is an AI-powered civic issue reporting platform that promotes transparency and accountability across Pune.

Features

- 📸 Smart Reporting — Upload photos and describe civic issues.
- 🤖 Gemini AI — Identify visible damage, estimate severity, suggest repairs, and recommend departments.
- 🔄 Duplicate Detection — Group reports about the same issue.
- 📊 Public Accountability — Track unresolved complaints and monthly performance rankings.
- ✅ Verified Repairs — Citizens confirm whether reported issues have been fixed.

Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python, Django
- Database: PostgreSQL
- AI: Google Gemini API

Goal

Make civic reporting transparent, accessible, and accountable — one complaint at a time.

Built as a hackathon project.
